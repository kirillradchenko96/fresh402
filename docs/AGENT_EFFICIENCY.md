# Server-workflow agent economics

[The current study](https://fresh402.com/agent-efficiency) measures the four new server-executed products, not the earlier client-orchestrated functions. 48 frozen sessions were planned across coding, competent warm-free and server-scoped conditions: 47 completed using actual Sol/Astra inference, with one upstream socket failure retained and no retry. Six alternate unchanged-field names were adjudicated separately while preserving the frozen automatic grader. Current scoped facts passed; Astra Cross coding omitted the original chain baseline, so full comparative coverage is not claimed.

Server sessions made zero project writes; custom-code sessions required implementation and persistence. In three paired Sol Website cases, the median paired complete two-task Developer-equivalent saving against building code was 30.9%, with server cheaper in two of three pairs. Competent warm-free implementations were usually cheaper; no general warm-free cash advantage is established. Astra has only one case per condition/family and is exploratory.

[All measurements](https://fresh402.com/agent-efficiency-results.json) separate cached input, output including reasoning, actual-model API-price equivalents, three service fees (baseline, first comparison, repeat), direct/Starter/Developer valuations and clearly labeled price-only counterfactuals. API equivalents are not subscription invoices. Later 10/100/1,000-task reuse is extrapolated, not measured longevity. The controlled application used local workerd/D1 and synthetic sources/credits; its timing excludes production networking, cold start and settlement. Closed Cloudflare staging separately accepted all four products, unchanged document observations and exact REST/MCP replay using existing staging credits. No new USDC payment was made for this study.

Historical five-pair oasdiff/token figures measured a different client-orchestrated experiment and are not claims about these new server products. These commissioned evaluations are not organic customer reviews.
