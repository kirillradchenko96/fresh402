# Circle Gateway — disabled, not a supported purchase path

Root `circle_gateway.enabled` is false. Gateway-funded settlement/withdrawal has no current real-money acceptance; do not fund a Gateway balance or sign an authorization for Fresh402 on the basis of this guide. This disabled rail is separate from enabled native MPP, direct x402 and prepaid.

Use [current payment methods](MPP.md), [live plans](https://api.fresh402.com/v2/prepaid/plans) and [payment/recovery requirements](API.md#payment-and-recovery). Never reinterpret an original historical payment or replace an uncertain authorization. This page preserves the existing public guide URL without promoting inactive prototype instructions. [Historical guide](https://github.com/kirillradchenko96/fresh402/blob/2d83fa3dc13008df75081980484aca724e9bd607/docs/CIRCLE_GATEWAY.md).
