# Bounded machine trial

Inspect [GET /v3/agent-trial](https://api.fresh402.com/v3/agent-trial) before enrollment. The approved operating window is October30,2026 00:00UTC through November29,2026 00:00UTC. The live enabled field is authoritative; disabled means no free execution. Eligible NEW identities receive a one-time maximum100Checks (up to20/day), plus one each Extract, Smart Diff, OpenAPI Contract Diff, Contract Watch, Wallet Watch and Token Facts. Existing identities retain their original allowances (including legacy2Checks), consumed quota and original expiry; rotation does not upgrade or renew them.

Maximum lifetime is30days clipped to November29. Late joins get fewer days; this is not a rolling30day promise for every agent. Purchased credits do not inherit this trial expiry. The separate human Web trial retains its own allowances, Turnstile requirement and earlier November14operating gate.

## Unfunded machine enrollment

Free metadata and Register require no wallet. For a product trial, an unfunded EOA requests POST /v3/agent-trial/challenge with a nonzero wallet address, then signs the exact EIP-191 personal_sign ownership message. The caller must explicitly authorize its own signing policy. No CAPTCHA, USDC, gas, token approval, funded wallet, purchase or browser is required. A wallet proves control, not a unique person/agent; an ordinary MCP client cannot supply a signer by connecting alone.

POST /v3/agent-trial/claim accepts only wallet, the original unexpired challenge_id and its65byte signature. Challenges bind wallet, host and network and are consumed once. Save the returned fm_ key privately. Use X-Fresh402-Trial-Key plus a persisted16–128character Idempotency-Key on normal REST tool calls or the MCP HTTP connection. Never mix trial/payment/prepaid credentials. Read GET /v3/agent-trial/quota. Replay the exact original tool/input/key for a retained result; a new operation key means new work. Rotation invalidates the old credential and preserves original quota/expiry. An expired identity cannot renew.
